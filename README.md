#กิจกรรมวันนี้

1. Git คืออะไร** = คือระบบควบคุมเวอร์ชัน (Version Control System) ที่ช่วยให้ผู้พัฒนาซอฟต์แวร์ติดตาม แก้ไข และจัดการประวัติของไฟล์โค้ดได้อย่างเป็นระบบและปลอดภัย

2. การทำงานของเว็บไซต์ทำงานอย่างไร = ผู้ใช้ค้นหาเว็บไซต์ แล้วเซิร์ฟเวอร์ส่งข้อมูลมาแสดงบนหน้าจอ ทำงานผ่านการสื่อสารระหว่าง เบราว์เซอร์ → DNS → เซิร์ฟเวอร์ → เบราว์เซอร์

3. เว็บไซต์ต่างจากเว็บแอปพลิเคชันอย่างไร = เว็บไซต์เน้นแสดงข้อมูลให้ผู้ใช้ดู ส่วนเว็บแอปพลิเคชันเน้นให้ผู้ใช้โต้ตอบและทำงานผ่านระบบได้ เช่น กรอกข้อมูล สั่งซื้อ หรือจัดการข้อมูล
